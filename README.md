# mykh-tasks

Данные для бота задач MYKHTRADES. Кода здесь нет.

- `plan.json` — ежедневная норма (`daily`) и задачи по дням недели (`weekdays`). Правит Claude из чата «Штаб» после отчёта недели.
- `inbox.json` — разовые задачи. Бот импортирует записи с `date <= сегодня`, которых ещё нет в базе (по `id`).

Категории: `traffic` 🚀 · `audience` 💬 · `funnel` 🔻 · `project` 🛠. Приоритет: 1 — важно, 3 — бонус.
