# Правила для Claude

Репозиторий — источник задач для Telegram-бота MYKHTRADES (бот читает его каждое утро в 07:30 по Будапешту).

- Разовая задача из любого чата → добавить объект в `inbox.json`: `id` = `ГГГГ-ММ-ДД-NN` (дата добавления + порядковый номер, уникальный), `date` = когда показать, `cat`, `priority` 1–3, `title` — одно действие, `note` — где контекст, `chat` — если работа идёт в конкретном чате.
- Старые записи из `inbox.json` не удалять и `id` не менять: бот сверяет по `id`.
- `plan.json` менять только по решению пользователя (обычно после воскресного разбора).
- Все задачи — только про проект MYKHTRADES. Главная цель — трафик: категория `traffic` важнее остальных.
- Проверять JSON перед коммитом (`python3 -m json.tool`). Коммитить сразу в `main`.
